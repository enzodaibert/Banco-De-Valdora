Configurar Firebase
O Banco de Valdora usa o Firebase Firestore para sincronizar dados entre todos os dispositivos em tempo real. A configuração é gratuita e leva menos de 5 minutos.
Como obter as credenciais:
  1. Acesse console.firebase.google.com → Criar projeto
  2. No menu lateral: Firestore Database → Criar banco → Modo de teste
  3. Ícone de engrenagem → Configurações do projeto → Seus apps → Adicionar app </> Web
  4. Copie os valores de firebaseConfig e cole abaixo
